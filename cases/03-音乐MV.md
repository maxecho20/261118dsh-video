# 03 音乐 MV，2D/3D 动作和音频卡点

沟通确认的是从实际歌曲的节拍和情绪推镜头。参考一是[《富士山下》MV 重制版](https://www.douyin.com/video/7698246233147624758)。已看到章节角标、雪夜像素角色等画面。参考二是[Opus 5.5 做 MV 六步教程](https://www.douyin.com/video/7698697526622440714)，从理解音乐、定画风、做统一角色、分镜、草图到成片迭代。使用可复用的制作技法，以原创或获授权音乐进入实测。配乐来源独立记录。

推荐用原创「大肥鱼」概念作为可辨识主角，做成独立的鲸形角色，保持同版角色。首轮 10–16 秒，16:9 横版，30 fps。可选 2D 或 3D；无论画法，都从音轨提取拍点，试听其中一段。进一步验建模时，可另做 3D 场景分支，交付可渲染场景，不以 2D 透视效果记录为建模。

## 验收

- 原音频、检测到的 beats/onsets、每个镜头的转场时点或关键动作帧作为证据。至少五个密度不同的重拍或音头，逐点试听并核对时间。
- 在 30 fps 成片中，五个预先选定的关键位置与实际拍点偏差目标 ≤2 帧。检查音乐起落是否对应视觉强弱，角色动作有没有完整性。记录偏差，不外推至所有音乐。
- 3D 分支需提供源场景（如 GLB、Blender 或可渲染的 Three.js 场景）、两角度或一小段环绕预览。记录形体、材质、光线及渲染方式。

## 调用提示

> 使用 ai-video-workflow 运行 Case 03。读本简报和可用音轨，先提取并校对真实音频的重拍、音头与段落，产出 beats.json，再做 10–16 秒原创小鲸段落，可自主选择 2D 或 3D。至少五处明确对拍，有 3D 时提交可编辑场景。提供 MP4、工程、音轨来源、拍点偏差和试听待检查项，输出到 runs/03-MV/hermes-golden-01。
