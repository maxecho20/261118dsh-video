## 01 真人口播｜给模型的提示词

```text
使用 ai-video-workflow，把「素材/01 真人口播/代码动画_前2分钟剪辑交接包」剪成一段能直接用在技术教程开头的真人口播。观众在前十秒要听明白“这是一套 AI 做代码动画的系统教程”，也要看到代码动画究竟能做出什么。

读 00_给剪辑师的任务.md、timeline/飞书原脚本_第01至10镜.md 和时间映射。用 Aroll 里的 1080p 底剪作主声轨。第一镜采用卡尔在原脚本最后一栏的构图意见：真人出镜，左上角切换素材。依次看 M43 产品发布片、M12 论文讲解、M01 水彩动画、M02 3D 动画，各选一眼能认出类型的动作。让类型名和当时的画面一致，保住人脸和字幕空间。现成一分钟成片只用于完稿后对照。

先交 8–12 秒、16:9、1080p30 的可播放片头。在自然语义边界收住，保留原声和自然语速，B-roll 静音。依据实听、脚本和词级时间戳校字，重点核对“系统教程”。导出后再听一遍切点，抽看字幕和画面是否同步。交 MP4、可编辑工程和剪点表，逐条写明素材文件、源入出点、成片入出点及选它的原因，另列工具实际调用和人工校字。保存到 runs/01-口播/ 的新目录。

片头过片后再扩到第 1–10 镜。第七镜按原顺序展示六种技术，第九镜给三个案例同屏留足观看时间，第十镜在“再一起淡入”收住，底剪参考出点 01:59.533。
```

**过片看点**　先正常播放，听开头是否被切断，看真人与左上角示例是否争抢注意力。再静音播放一次，看四个类型能否认出。用原声回查字幕里每一处术语修订，底剪已有的剪点单独标注。

## 02 产品动画｜给模型的提示词（iPhone 进化史）

```text
使用 ai-video-workflow，自主制作一支独立致敬 iPhone 进化史的横版产品动画。主题是“iPhone 从 2007 年到现在如何一步步进化”。给认识苹果、但没有研究过 iPhone 产品史的观众看。开头十秒内，让观众看懂至少一次具体变化：上一代 iPhone 的某个形态或交互，到了下一代发生了什么改变？

请自行决定讲哪几代、用什么视觉线索串起它们（如屏幕形态、Home 键消失、材质变化）、采用 2D 还是 3D。从公开原始资料中自行搜索、选择和裁剪真实产品参照。简述选择理由，核对代际、外形和日期。每个采用的参照留原始链接、素材文件名、采用部位或视频时间段、使用方式；区分直接入画与据图重绘。素材条件影响某个镜头时，自行选择能成立的表现方式。

先提交 8–10 秒可播放样片，16:9、1080p30，靠画面与声音讲清变化。把片子、可编辑工程、来源表和实际操作记录放在 runs/02-苹果手机进化/ 的新目录。说明哪里用到了真实素材，以及哪一次剪裁或运动设计帮助观众理解产品。样片过片后再扩成约 40–60 秒的致敬短片，片尾标明独立制作。
```

**过片看点**　先遮住型号和年份，请观看者说出“我看到了什么变化”。再逐镜对照真实 iPhone 图，看机身、屏幕比例、Home 键/刘海/灵动岛、材质是否属于同一代。素材表至少能回溯样片中的两代 iPhone。编辑复核可从这些一手资料入手。[Apple Newsroom](https://www.apple.com/newsroom/) · [初代 iPhone 发布稿](https://www.apple.com/newsroom/2007/01/09Apple-Reinvents-the-Phone-with-iPhone/)

## 03 音乐 MV｜给模型的提示词

```text
使用 ai-video-workflow，为孙燕姿《第一天》做一段 10–16 秒、16:9、1080p30 的音乐动画。主角是为此次测试设计的 DeepSeek 小鲸。创意起点是“小鲸第一次跃出水面”：水下用简洁的 2D 轮廓和气泡交代蓄力，镜头跟着它破水，让观众感到空间突然打开。可以用同一套 2D 动画贯穿，也可以切入有真实空间的 3D 镜头。保持眼睛、尾鳍和体色可辨认。

先在「素材/03 音乐 MV」定位本次可用于测试的歌曲音频。记录具体版本、文件名和截取的原曲入出点。没有音频时交角色草图方案与待标拍动作表，明确待补的输入。音频到位后先试听，找一段有蓄力、重音、舒展的完整乐句，用项目 beat-map.py 的 librosa 路径提取 beats 和 onsets，再回听修正。若只有音头检测可用，记录候选音头并由试听确定强拍。

先按音乐预选至少五个可听辨的锚点，记下听见的声音，然后安排转头、摆尾、破水、溅起水花、弧线落回水面等动作。弱拍可以留在同一镜头，最重的一拍留给最值得看的动作。按实际乐句决定动作与次序，保留一处能看完整的连续运动。

导出带本次测试音轨的 MP4、可编辑工程、角色设定、beats.json 和五点对照表。表内列原曲秒数、片内秒数、听到的声音、动作落点帧、偏差帧及试听结论。若受运行环境限制无法试听，标出待人耳复核的点。选择 3D 时附可编辑场景和两个视角。保存到 runs/03-MV/ 的新目录，记下实际工具和人工介入。
```

**过片看点**　先闭眼听选段，在独立播放中标出重音，再对照动作。30 fps 下以五个预选点各自偏差 ≤2 帧为测试目标，并记录刻意提前的预备动作与实际撞点。最后看一次完整乐句，检查角色是否连贯、动作有没有时间展开。原曲版本和可用范围随音频登记，公开发布另核使用范围。[歌曲版本参考](https://www.youtube.com/watch?v=y3lP_gPjlUo) · [成片参考](https://www.douyin.com/video/7698246233147624758) · [制作过程参考](https://www.douyin.com/video/7698697526622440714)
